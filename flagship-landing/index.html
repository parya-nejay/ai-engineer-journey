IT Helpdesk RAG

Retrieval-augmented answering over internal IT documentation.

Try it

Try: How do I reset my password? · How do I set up the printer? · What is the capital of France?

What it does

Answers IT support questions from a document corpus, and refuses to answer when the documents don't cover the question — instead of inventing one.

What I measured

  • 9/9 on a custom eval set (refusal, paraphrase, keyword, fact-check cases)
  • Retrieval is ~80% of response time — the LLM is only ~1.4s
  • BM25 + RRF fusion cost 0ms; 100% of retrieval cost is embedding the query

What I turned down

  • Hybrid retrieval — built it, A/B tested it, it lost. Shipped vector-only.
  • A 20x embedding speedup — needed 300–500MB of PyTorch in a 512MB container.
  • Optimizing the 7.4s response — proved it was shared CPU, not my code.
